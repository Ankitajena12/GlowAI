# GlowAI
🌿 GlowAI — An AI-powered skincare assistant built with RAG (Retrieval-Augmented Generation). Uses LangChain, ChromaDB, and Ollama (Llama3) to answer skincare questions from a custom knowledge base. Features a Gradio web UI with voice input, image upload, and dermatologist finder. Runs 100% locally — no API key required.
